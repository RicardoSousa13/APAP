# Visual Direction — Working Notes

This document is the evolving creative brief for version 1.0. It records decisions before they are translated into the website.

## Core Tension

The identity balances wandering and rigor: a practice of close observation, botanical knowledge, drawing, and spatial analysis.

| Wandering | Rigor |
| --- | --- |
| Organic | Structural |
| Observation | Analysis |
| Natural | Architectural |

## Desired Character

- Personal, quiet, and intelligent
- Editorial rather than corporate
- More like a publication, archive, or field notebook than a conventional portfolio
- Predominantly black, white, and neutral grey
- Precise, calm, and slightly unexpected
- Centred on the work itself
