# Alexandre Parente — Landscape Architect

Personal portfolio website for Alexandre Parente, a landscape architect working between botanical observation, drawing, organic systems and architectural precision.

## About

The website is an extension of Alexandre Parente's visual identity and practice. His approach to landscape architecture is grounded in walking, observing and reading the territory before defining any formal intervention.

The identity explores the tension between two complementary conditions:

**Wandering / Rigor**
**Organic / Structural**
**Observation / Analysis**
**Natural / Architectural**

The website should reflect this tension without becoming visually noisy or overly experimental.

## Visual Direction

The visual language is intentionally restrained and predominantly monochromatic, using black, white and neutral greys.

Typography is a central element of the identity. A custom typographic system explores organic forms, variable weight and intersections between letters, drawing a parallel between botanical growth and architectural structure.

The visual system should feel:

- Quiet
- Editorial
- Spatial
- Precise
- Organic
- Slightly unpredictable
- Timeless

## Website Principles

The website should prioritise the work and the act of looking.

Motion should be subtle and considered. Elements may wander, overlap or shift, but always within an underlying structural system.

Avoid:

- Generic architecture portfolio layouts
- Excessive animation
- Unnecessary cursor effects
- Loud transitions
- Overly technological aesthetics
- Decorative interactions without conceptual purpose

The website should feel like a **living graphic system**: structured underneath, but capable of movement and variation.

## Structure

Version 1.0 will include:

- Home
- Projects
- Individual project pages
- About
- Contact

Projects will be identified primarily by **name and location**, rather than numerical indexing.

## Content

Initial development will use placeholder text and imagery.

The final website will incorporate:

- Alexandre's projects
- Landscape and botanical photography
- Drawings and studies
- Generated graphic textures
- Project descriptions
- Biography and contact information

## Development

This repository contains the first digital implementation of the Alexandre Parente visual identity.

The project is currently in active development. The first priority is to establish a strong layout, typography and interaction system before expanding the content.
